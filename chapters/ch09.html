30 秒开场The 30-second open

中文

短链两个 endpoint：POST /shorten 把 long URL 换成短码，GET /{code} 用 302 跳回长链。读多写少，存储也不大。Hard part 有两个：默认 302 而不是 301，因为要 Analytics；短码用 base62 加号段，不用 hash 截断，更不用 Snowflake。

范围就这么大。不要主动画全球 CDN 加数仓，除非他们追问热点。

English

Two endpoints. POST /shorten turns a long URL into a code. GET /{code} returns a 302 to the long URL. Reads dominate, and the data is small. Two hard parts: default to 302 rather than 301 because we need analytics, and build the code as base62 of a counter — not a truncated hash, and not a Snowflake.

That is the whole scope. Do not volunteer a global CDN plus a warehouse unless they ask about hot keys.

读路径，一笔一笔画Draw the read path one stroke at a time

中文

买到 buy-in 之后再拆。schema 够用就停：short_code 做主键，对应 long_url，可选 expires_at。不需要 JOIN。

写路径口头补一句：自定义码先查占用；同一条 long URL 可以用反向索引返回已有短码，避免重复创建。

English

Split the picture only after buy-in. Stop the schema when it is enough: short_code as the primary key, long_url, optional expires_at. No join.

Say the write path in one breath: a custom alias checks for a taken code, and a reverse index can return the existing code for the same long URL so you do not mint duplicates.

这三层就是 Ch38 · 缓存 在这道题里的用法。Those three layers are Ch38 · cache applied to this question.

收尾，不要说完美Close without saying perfect

中文

bottleneck你怎么接
热点短码本地 LRU，加上 Redis；同一码同时 miss 时合并回源
被枚举、被刷创建创建接口限流；同一 long URL 返回已有码
缓存和 KV 不一致短 TTL，删除或过期时主动失效
原书更偏向 301 的那一版

旧材料常把 301 当默认，理由是省回源。现在短链要统计、要改目标、要过期，默认改成 302。埋点走队列，不挡跳转。301 只留在永久搬家。

下一道完整题是通知系统，计划 2 再写。自测：合上页面，用开场那 30 秒把 302 和「不用 Snowflake」讲一遍。

English

BottleneckWhat you say
Hot codeLocal LRU plus Redis, and collapse concurrent misses
Enumeration and create abuseRate-limit creates; return the existing code for the same long URL
Cache and KV disagreeShort TTL, and invalidate on delete or expiry
The book leaned toward 301

Older notes often default to 301 to save origin traffic. A shortener that counts clicks, changes targets, and expires links now defaults to 302. Analytics goes through a queue and does not block the redirect. Keep 301 for a permanent move.
