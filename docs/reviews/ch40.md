## 代码、真实运行与保证范围

三个代码块都只出现一份，双语说明共用。完整实现为 [ProtocolContracts.java](../../examples/ch40/ProtocolContracts.java)，摘录由 [sync.mjs](../../examples/ch40/sync.mjs) 逐字同步。

| 摘录 | 输入、输出和正常路径 | 关键反例与限制 |
|---|---|---|
| `budget` | 本地单调时钟、原总预算和回程预留 → 下游剩余 duration；300−40−20=240 ms，再过 100 ms 只剩 140 ms | 同一个 Budget/operation key/总 attempt 计数；到期为 0，第三次 attempt 拒绝。retrySafe 是外部业务证明；不实现幂等、gRPC stub 或远端时钟 |
| `resume` | 应用已持久应用的 scope/epoch/seq、同截面的保留范围、本次鉴权 → REPLAY_AFTER / RESET / INVALID | oldest=43 时 42 可补，41 必须 RESET，high=50 时 51 拒绝；越权/跨 scope 拒绝。read/tail 必须 pin 或再查裁剪；分类函数不生成快照、不实现分布式日志 |
| `writer` | 单事件循环、65,536 B cap、2 s 无进展界限 → 接收/排出/关闭 | 正确处理部分写、零写、精确满额、溢出、I/O 错误；首待发字节开始计时，正数写才续时；关闭清空且不能隐式复活。sink 必须真非阻塞并具有有界缓冲契约 |

成功 offer 让 writer 独占数组；失败保留调用者所有权并关闭流。64 KiB 仅为该队列 payload，至多一块有界 staging、TLS、内核、模型和对象单独预算。模型不把“框架已接收”当“已出网”；对真实 sink 是否隐藏无界队列，必须审查适配实现，ByteBuffer 检查不能证明该属性。无进展定时器也不限制慢速 trickle 的总生命周期，另需整体 deadline/最低吞吐策略。

[verify.py](../../examples/ch40/verify.py) 另用真实 SQLite 本地文件推演：浏览器已见 E:43，但应用值100/游标42；投影+7后故障，事务回滚为100/42；重建到新 generation 后旧 handler 拒绝，重放一次提交107/43，重复43不再次加7，缺口45不推进。这个事务只覆盖一个客户端的本地状态与游标，不覆盖外部调用。

可复现入口：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 examples/ch40/run.py
node examples/ch40/sync.mjs --check
node tools/audit-chapter.mjs ch40
node docs/reviews/ch40-browser.mjs
node docs/reviews/ch40-frames.mjs after
PYTHONDONTWRITEBYTECODE=1 python3 docs/reviews/ch40-contacts.py after
node docs/reviews/ch40-reading.mjs
```

Java 默认使用 `/Library/Java/JavaVirtualMachines/jdk-17.0.10.jdk/Contents/Home`，仅标准库；Python 仅标准库，接触表额外使用本环境 Pillow。Playwright 复用主代理指定模块与 Google Chrome。实际 Java 以 `--release 17` 编译执行，产物在自动删除的临时目录。运行说明见 [README](../../examples/ch40/README.md)。
