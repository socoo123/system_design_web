## 更正与明确的边界

| 旧内容的不足 | 本轮结果与证据 |
|---|---|
| 无核心实现，仅以“原子发布/幂等/固定快照”叙述保证 | 3 段真实源摘录，完整源码可运行。SQLite 的 log/MVCC/root/alias/pin 在同一 authority 库；独立向量引擎没有被假装纳入该事务。 |
| model/metric 验证未落实现，调用方可能在 alias 切换前后混模型 | 先 pin 本次 bundle，再按其 schema 验证 query model/dims/metric；旧 embedding 拒绝或由上游重算。写 token 另绑定 space/schema 身份，模型切换后即使 epoch/LSN 数值相等也拒绝旧 space token。Java 拒绝非有限向量、cosine 零向量、非有限距离，cosine 双方归一化；三种 metric 转为低值优先。 |
| 单片 Manifest 与“最低 searchable 位点”不足以保证固定读取 | root 固定实际 cut 与 vector/payload/live，MVCC 选历史行后保存不可变 JSON；重试必须匹配同 bundle/root/epoch/精确 cut。仅 applied≥cut 然后读当前 delta 被明确否决。 |
| 全分片版本发布只在段落中提及 | required shard 全集、所有 roots/checksum、可信 barrier 与 alias seq CAS 同一 SQLite 事务；missing/stale/CAS loser 不发布。生产还需要校验并实际加载 root 的 incarnation/cut/hash 回执，示例没有执行该适配。 |
| complete、凑够 k、允许集耗尽容易混为一种“成功” | complete 仅为分片覆盖；Java 的 K_REACHED 仍可能漏最近点。允许集真耗尽/近似短缺/缺片分开。gather 拒绝混代/移动 cut，迟到旧 attempt 不计覆盖，默认缺片无普通 hits；显式 opt-in 才 PARTIAL。 |
| A10 原默认“最多旧 2 s”缺少可运行时钟/屏障实现 | **默认契约收窄为已发布固定 bundle**；写 token 不覆盖则等待完整新 bundle 或失败。2 s 保留为需时钟误差/屏障采样年龄证明的可选要求，明确本例未实现。Ch30 既有调用契约未依赖这 2 s（主代理核对）。 |
| 回退只说旧索引追写，未具体绑定全片发布 | 旧 encoder/space 需继续摄取并重新生成覆盖当前 barrier 的 roots/bundle；仅留老文件不足。换模型必须新 supplied vectors；源游标回放、物理搬片与真实迁移未执行。 |
| D6 F4/F5 同次 A 尝试同时画成功回程与拒绝 | 成功 lane 改为 muted，文字改为 no result from A；拒绝到 Query svc，再重试同 root/固定 cut 的 B。 |

固定每片 cut 的位点向量只是一组可复读状态，**不是跨片单一时刻/事务快照，且无跨片原子写**。

## 限制与交接

实际 Python 3.11.8 / SQLite 3.51.0，Java 17.0.10；SQLite 单写者锁比生产行锁更粗。
注入回滚、重开与双连接竞争不等于电源故障、复制切主或网络分区实验。
未运行真实向量库/ANN recall 压测、跨进程/跨节点复制、远端 root 加载、embedding、
时钟证明、物理迁移、真实源游标增量回放或生产负载。
Java 小 Map 的允许集计数、Python JSON roots 与无限期幂等/pin 是明确的教学简化。
生产租约过期须先阻止旧 worker 访问资源才能回收，不能直接删 pin。
