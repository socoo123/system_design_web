## 技术纠错候选

- 访问表把所有“分区 KV”都写为故障时放松 quorum，应限定本章 Dynamo 风格；事务型 KV 另看契约。
- 把列存统称只读、把行存/B+Tree/LSM排成必然映射，须限定本章分析路径；现代列式引擎能力不能由布局推断。
- “向量只回答近似近邻”“一两跳用索引、多跳才图”过于绝对，改成工作负载候选而非产品能力判定。
- “副本可承接旧一秒列表”是目标，不是异步复制自动兑现；超过新鲜度阈值须回主/拒绝，确认读还需新快照。
- 检查失败前提交/回执窗口的说法：提交前应回滚，提交状态未知应查幂等记录，非自动换键；只有安全故障域和提升规则才能限定 RPO=0。
- PostgreSQL18 WAL/复制/Read Committed、RocksDB Write Stalls、Bigtable/Dynamo/LSM/Dremel原论文与S3条件写用一手文档当日核对，引用就近，不将自设数字冒称实测。
